# Real estate: listing summarizer and comparable-property finder

An agent that summarizes a listing in plain English, finds the most similar
nearby properties, and gives a comps-based read on whether the price is fair.

## Run

```bash
python -m examples.real_estate_listings.run                       # offline mock provider
python -m examples.real_estate_listings.run --provider openai \
  --task "Summarize L-2033 and compare it with active listings nearby."
python -m examples.real_estate_listings.run --provider ollama -v
```

## Tools

| Tool | What it does |
|---|---|
| `search_listings` | Filter by neighborhood, property type, status, bedrooms, max price |
| `get_listing` | Full record for one listing |
| `summarize_listing` | Headline facts, $/sqft vs. neighborhood median for the same type, features |
| `find_comparables` | Top-N similar properties within a radius, with a value estimate |

### Comparable scoring

Candidates within `radius_km` (haversine distance) and of the same property
type are scored 0-100:

```
score = 100 * (1 - Σ wᵢ · penaltyᵢ / Σ wᵢ)
```

| Factor | Weight | Penalty (capped at 1) |
|---|---:|---|
| distance | 0.30 | distance / radius |
| living area | 0.25 | abs(Δ sqft) / subject sqft |
| bedrooms | 0.15 | abs(Δ beds) / 3 |
| bathrooms | 0.10 | abs(Δ baths) / 2 |
| age | 0.10 | abs(Δ year built) / 40 |
| lot size | 0.10 | abs(Δ lot) / subject lot (skipped for condos) |

The estimate is the median comp $/sqft times the subject's square footage,
with the min/max comp $/sqft as a range. It is a rough indication, not an
appraisal. Tune `WEIGHTS` in `tools.py` for your market.

## Data (synthetic)

`data/listings.json` holds 36 **synthetic** listings in a fictional city
("Fairhaven") across three made-up neighborhoods, generated by
`data/generate_data.py`. Addresses, coordinates and prices do not describe
real properties. Point `--data-dir` at a folder with your own `listings.json`
(same fields) to use real data.

## Responsible use

The system prompt tells the model to stay factual and avoid describing or
steering by neighborhood demographics, in line with fair-housing rules. Keep
that instruction if you adapt the prompt.

## Files

- `tools.py` - listing model, scoring and the tool registry
- `prompts.py` - system prompt, default task and the scripted mock run
- `run.py` - CLI entry point
- `tests/` - offline tests for the tools and the agent loop
